# Odd Sum

Implement `OddSum.sumOdd(int[] values)`.

The method returns the sum of every **odd** element of `values`. An empty array returns `-1`.

[task][Sum the odd values](<testid>1</testid>,<testid>2</testid>,<testid>3</testid>)

---

## Requirements

1. Use the **Stream API** to traverse the array.
2. Return `-1` for an empty array.
3. Throw `IllegalArgumentException` when `values` is null.
